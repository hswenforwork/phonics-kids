# custom：自己上傳的音檔與圖片

把自己裁切好的音檔、想用的圖片放在這個資料夾，再到表單填上檔名，網站就會改用你的檔案。

## 怎麼上傳

1. 在 GitHub 打開這個資料夾，按右上角「Add file → Upload files」（手機請先切換成「電腦版網頁」）。
2. 把檔案拖進去，按「Commit changes」。
3. 約 1～3 分鐘後，自動流程會把音檔轉成 mp3，家長模式的下拉選單就會出現新檔案（重新整理頁面）。

## 支援的格式

- 音檔：mp3、m4a、wav、aac、ogg、webm、flac、aiff、caf…（mp3 會原封不動使用；其他格式只轉成 mp3，不改聲音內容）
- 圖片：png、jpg、gif、webp、svg

## 檔名

- 隨你取，例如 `k.m4a`、`cake-a.mp3`、`我的k.wav`。表單填檔名時可以省略副檔名。
- 建議不要跟共用檔名（`k.mp3`、`eɪ.mp3` 這種「音素.mp3」）一模一樣，避免看不出是自訂的還是共用的。
- 換新版本：上傳同名檔案覆蓋即可，表單不用改。
- 刪除檔案後，表單裡用到它的地方會在「自動_檢查」欄提醒你，網站暫時改回 AI 語音。

## 檔案用在哪裡（在表單填檔名）

| 想換的聲音 | 填在哪裡 |
|---|---|
| 某個聲音在所有字卡上（例如所有字的 /k/） | `data/sounds.csv` 的「音檔」欄，或家長模式「🔊 聲音表」 |
| 某個字的某一格（例如只換 cake 的 a） | `data/words.csv` 的「音素音檔」欄那一格，或家長模式字卡的「✏️ 編輯」 |
| 某個字的整字發音 | `data/words.csv` 的「整字音檔」欄 |
| 某個字的圖示 | `data/words.csv` 的「圖示」欄填圖片檔名 |
