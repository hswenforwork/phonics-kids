# phonics-kids｜拼音小探險

給 5 歲起的孩子使用的自然發音拆音節小工具，介面為繁體中文。

## 兩種模式
- **孩子模式**：選主題圖卡（程度約 Kid's Box New Generation Starter～Level 1），點字母、點音節、按「拼起來」聽發音，學會了就按「我會了」得到星星。
- **家長模式**：輸入任何英文單字，顯示最終音節劃分、中文講解、英文講解，以及可展開的七步分析表與自檢清單；中文意思可以手動修正。

## 拆音節原則
以實際發音（IPA）為準，拼字規則是輔助：
Step 0 查發音 → 1 一眼認讀字 → 2 複合字 → 3 字首字尾 → 4 找母音 → 5 好朋友字母（二合字母）→ 6 動物法則（🐰 兔子、🐯 老虎、🐫 駱駝、🦁 獅子、🐢 烏龜）→ 7 魔法 e、不發音字母。

發音來源依序為：內建單字庫 → 線上字典（Free Dictionary API）→ 都查不到時依拼字規則推測，並標示「未經發音驗證」。庫外單字的中文意思由 MyMemory 自動翻譯，家長可修正。

## 注意
- 聲音使用瀏覽器內建語音。單一字母音容易被念成字母名稱，所以點字母時改念代表字（例如 a → apple）。
- 學習進度與修正的中文只存在各自的裝置，不會上傳。
- iPad／iPhone：用 Safari 開啟後按「分享 → 加入主畫面」，就能像 App 一樣使用。

## 開發
純靜態網頁，無需建置。規則引擎測試：`node tests/engine.test.js`
