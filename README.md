# phonics-kids｜拼音小探險

給 5 歲起的孩子用 Elkonin Boxes（格子）學自然發音的小工具，介面為繁體中文、發音為英式（配合劍橋 Kid's Box）。

👉 第一次使用請看 [SETUP.md](SETUP.md)：開啟網站、申請 Google 語音金鑰、產生語音檔。
👉 教學方法與格子規則請看 [references/rules.md](references/rules.md)（網站家長模式的「📘 教學指南」）。

## 兩種模式
- **孩子模式**：九個等級（0 音節拍拍手、1 字母的聲音、2 短母音小字…8 長長的字），每個字三關：推代幣 → 放字母 → 滑讀，過關得貼紙。
- **家長模式**：查任何字的格子拆解與中英講解；編輯單字、聲音表；教學指南；標記不熟的字母、管理進度。

## 自己維護單字與音檔（不需要寫程式）

所有單字都放在 `data/` 裡的三張表（CSV，可以用 Excel／Numbers 開）：

| 表 | 一列是 | 用途 |
|---|---|---|
| `data/words.csv` 單字表 | 一個字 | 新增單字、改中文、主題、圖示、音標、音節、整字音檔、**每一格的音素音檔** |
| `data/sounds.csv` 聲音表 | 一個聲音（例如 /k/） | 換掉某個聲音在**所有字卡**上的音檔 |
| `data/exceptions.csv` 例外表 | 一個例外 | 規則判斷錯時，指定某個字的「第幾格改念哪個音素」 |

自己的音檔與圖片上傳到 `custom/` 資料夾（說明見 [custom/README.md](custom/README.md)）。

### 三種修改方式（擇一）
1. **家長模式表單頁（手機最方便）**：查一個字 →「✏️ 編輯這個字」或「➕ 加入單字表」；「🔊 聲音表」換共用音檔。按「送出到 GitHub」會開啟預填好的申請單，按 Submit 即可。
2. **用 Excel 改 CSV（電腦）**：在 GitHub 下載 CSV → Excel 修改 →「另存新檔」選 **CSV UTF-8（逗號分隔）** → 上傳覆蓋。
3. **GitHub 網頁直接改**：打開 CSV 按鉛筆圖示編輯（純文字，逗號分隔）。

送出或上傳後約 1～3 分鐘網站自動更新；在 GitHub 的 Actions 頁面可以看到「同步單字表單」的結果摘要。

### 單字表的欄位
| 欄位 | 怎麼填 |
|---|---|
| 英文單字 | 必填 |
| 中文、圖示、音標 | 可以空白，系統自動補上（中文自動翻譯、圖示自動配 emoji、音標查英式字典）；填了就以你的為準 |
| 主題 | 例如「動物」，也可以打新的主題 |
| 圖示 | emoji，或 `custom/` 裡的圖片檔名 |
| 音節 | 多音節字才需要，例如 `ti-ger`；空白依規則自動拆 |
| 整字音檔 | 空白用 AI 語音；填 `custom/` 裡的檔名就改用你的 |
| 音素音檔 | 系統自動填好每一格目前用的檔，例如 `k.mp3｜eɪ.mp3｜k.mp3｜—`。把其中一格改成 `custom/` 裡的檔名，就只換這個字的這一格；`—` 是不發音的格子 |
| 啟用 | `是`／`否`（否＝先不放上網站） |
| 自動_… | 系統填寫（等級、音節、音節數、格子、音素、檢查結果），手改會被蓋回 |

「自動_檢查」欄會寫出這一列的問題（例如找不到音檔、格數不對），沒問題時是 ✓。

### 聲音播放的優先順序
1. 單字表「音素音檔」指定這一格的自訂音檔
2. 聲音表「音檔」指定的共用自訂音檔
3. AI 語音檔（Google 英式女聲，依 IPA 預先產生）
4. 瀏覽器內建英式語音（暫時替代）

## 開發
純靜態網頁，無需建置。網站讀 `data/sheet.json`（由 `scripts/sync-sheet.cjs` 從三張表產生，請勿手改）。
- 同步表單（不上網查資料）：`SYNC_OFFLINE=1 node scripts/sync-sheet.cjs`
- 規則引擎測試：`node tests/engine.test.js`
- 對照 rules.md 檢查每張字母卡的發音：`node tests/audit-rules.cjs`
