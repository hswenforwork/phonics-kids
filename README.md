# phonics-kids｜拼音小探險

給 5 歲起的孩子使用的自然發音拆音節小工具，介面為繁體中文、發音為英式（配合劍橋 Kid's Box）。

👉 第一次使用請看 [SETUP.md](SETUP.md)：開啟網站、申請 Google 語音金鑰、產生語音檔。

## 兩種模式
- **孩子模式**：選主題圖卡（程度約 Kid's Box New Generation Starter～Level 1），點字母聽單音、點音節、按「拼起來」。每個字都有 **🔲 音素框練習**（Elkonin Boxes）：
  1. **推代幣**：先聽示範，再一個音推一個代幣進格子
  2. **放字母**：把字母卡（好朋友字母 sh、ee 是一張卡）拖進對的格子
  3. **自己拼**：從字母卡和干擾字母中，自己拼出單字（sh 要用 s 和 h 自己組）

  每過一關得一顆小星，三關全過得大星星 🌟；不發音的字母放在虛線框「🤫 不出聲」。
- **家長模式**：輸入任何英文單字，顯示音節劃分、音素框、中文講解、英文講解，以及可展開的七步分析表。可用 GitHub 申請單「加入單字庫」「換主題」「回報錯誤」。

## 拆音節原則
以實際發音（IPA）為準，拼字規則是輔助：
Step 0 查發音 → 1 一眼認讀字 → 2 複合字 → 3 字首字尾 → 4 找母音 → 5 好朋友字母 → 6 動物法則（🐰 兔子、🐯 老虎、🐫 駱駝、🦁 獅子、🐢 烏龜）→ 7 魔法 e、不發音字母。

## 聲音來源（依序）
1. AI 語音檔：Google Cloud Text-to-Speech 英式女聲，依 IPA 預先產生整字、音節、單音（`audio/`）
2. 字典真人錄音：只用於庫外單字的整字
3. 瀏覽器內建英式語音：AI 語音檔產生前的暫時替代，較不精準

## 資料
- 內建單字庫：`js/data.js`（英式 IPA）
- 申請單加入的字與修正：`data/custom-words.json`（由自動流程維護）
- 闖關進度只存在各自的裝置

## 開發
純靜態網頁，無需建置。規則引擎測試：`node tests/engine.test.js`
